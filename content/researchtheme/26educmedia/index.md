Making good educational media is hard: it requires content knowledge, pedagogical abilities, production skill, and a lot of effort. I want to create tools that reduce this burden. Some of this is "me-search": I want the tools to improve my own teaching. However, intellectually, it connects many of the things I am interested in: automated media generation, understanding how design connects to communicative effectiveness, human-automation collaboration, etc.

<!--more-->

This theme is a fledgling research project. It involves returning to some of the things I've done of the past decades, and building on a new generation of capabilities (e.g. using AI that can understand content and synthesize imagery on the spot).
